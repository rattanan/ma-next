Apply these rules when the task involves:
- Creating or redesigning pages/components
- Choosing layout, colors, typography, spacing, or charts
- Reviewing responsive behavior and accessibility
- Improving an existing UI

Do not apply these rules to backend-only, database, DevOps, or debugging tasks.

Before coding:
1. Identify the product type and target users.
2. Propose the design direction briefly.
3. Reuse the project's existing components and design tokens.
4. Avoid unnecessary dependencies.
5. Validate mobile, tablet, desktop, accessibility, loading, empty, and error states.
