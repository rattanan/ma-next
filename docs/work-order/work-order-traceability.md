## Acceptance suite required before declaring the module migrated

At minimum: manual create; approved-notification conversion and unapproved rejection; PM and shutdown generation; import reconciliation; assignment/reassignment and unauthorized assignment; every valid/invalid transition; backlog reason/resume/multiple entries; full job-step fields and required checklist; normal/OT validation; document/image security; material/tool issue lifecycle; execution acceptance/LOTO/test/handover; atomic completion; reject/return/approve/close; audit/history/notifications; report golden comparisons; tenant/site isolation; direct-status rejection; concurrency/idempotency; responsive mobile critical flow.
